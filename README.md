Desarrollo software desde 2024 en **CeSPI (UNLP)**, sobre un sistema que usan **millones de personas** todos los días. En paralelo trabajo como **freelance** y construyo productos propios, como **[facilito](https://pedifacilito.com.ar)**, que ya está en producción.
